# Theme Selection, Design System Adaptation & Strict Isolation Rules

## 🌟 DEFAULT THEME: Apple-Style Premium White (THEME #011)
**Unless the user explicitly specifies a different theme number (e.g. `Theme #001`, `Theme #027`), ALWAYS by default use THEME #011 (Apple Style Premium White).**

### Default Design DNA (Theme #011 — Apple):
- **Visual Personality**: Ultra-refined, pristine, gallery-curated, premium white, uncompromising product craft.
- **Color Palette**:
  - Primary Background: `#f5f5f7` (Signature Apple Off-White) and `#ffffff` (Pure White Card/Tile Surfaces).
  - Primary Text: `#1d1d1f` (High-contrast deep charcoal/black).
  - Accent / CTA: `#0071e3` (Apple Royal Blue) / `#0077ed`.
  - Muted / Eyebrow Text: `#86868b` (Refined neutral grey).
  - Borders & Dividers: `#d2d2d7` / `rgba(0,0,0,0.08)` hairline borders.
- **Typography**:
  - Display Font: `SF Pro Display, -apple-system, BlinkMacSystemFont, "Plus Jakarta Sans", sans-serif`.
  - Scale: Giant display headlines (56px-80px), `-tracking-[0.03em]`, balanced body (17px).
- **Component Language**:
  - **Navigation**: 44px sticky frosted navbar (`backdrop-blur-xl bg-white/80 border-b border-black/5`), centered logo, clean minimal links.
  - **Cards & Tiles**: 24px-30px rounded corner containers (`rounded-3xl` / `rounded-[24px]`), subtle 1px border, soft natural drop shadow.
  - **Buttons**: Pill-shaped action buttons (`rounded-full px-5 py-2.5 bg-[#0071e3] text-white hover:bg-[#0077ed]`) or text links with chevron right.
  - **Spacing**: Expansive museum-grade whitespace with centered 980px/1024px content boundaries.

## 🎯 CORE BEHAVIOR: PROJECT-AWARE DESIGN ADAPTATION (NOT BLIND COPYING)

When applying any theme (e.g. `Theme #011 Apple`, `Theme #002 Stripe`, `Theme #030 Craft`, etc.) to a project:

1. **Analyze the Target Project / Existing Codebase First**:
   - Understand what the project actually builds (e.g., e-commerce shirt store, developer tooling, crypto dashboard, SaaS landing page).
   - Preserve 100% of the project's actual functional requirements, business logic, content domain, workflows, and goals.

2. **Translate Design DNA — Never Copy Blind Placeholders**:
   - **DO NOT** clone the reference website's copyrighted products, trademarks, or brand names (e.g., if re-skinning an apparel store into Apple style, do NOT insert "iPhone" or "MacBook" text).
   - **DO** adopt 100% of the reference theme's visual craft, color tokens, typography scales, container geometry, border styling, lighting/shadows, micro-interactions, and UX feeling.

3. **Component Re-Engineering Example (Shirt Store in Apple Theme)**:
   - *Shirt Hero Showcase*: Apple-style giant typography, dramatic product photography lighting, minimal subtitle, pill button CTA.
   - *Product Grid*: Rounded bento containers, subtle 1px hairline borders, smooth hover zoom/glow, clean price hierarchy.
   - *Size & Color Picker*: Apple-style segmented pill switches with buttery transition physics.
   - *Checkout Drawer / Cart*: Frosted translucent backdrop-blur modal with crisp typography and royal blue action button.

4. **Strict Theme Isolation**:
   - Adhere strictly to the selected theme's design system tokens without mixing or borrowing styles from other themes.
